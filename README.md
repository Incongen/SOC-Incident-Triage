# SOC-Incident-Triage

## Cybersecurity Portfolio

A collection of projects, investigations, and practical exercises focused on development of skill in different areas such as triaging, digital forensics, etc.

### Objectives:
* Security Operations (SOC)
* Blue Team Operations
* Incident Response
* Digital Forensics
* Threat Detection & Analysis

### Projects:

Some blue team reports based on hands-on TryHackMe labs, for developing incident response and digital forensics skills.
* **Incident Investigations:** `Tempest`, `Boogeyman Trilogy`

### Tools Used:

* Elastic (Kibana)
* Volatility
* Wireshark
* Windows Event Viewer, Sysmon

Done in both Windows & Linux environments

### Further Development

* Continuously developing the previously mentioned skills with more incident responses, along with development of red-teaming and penetration testing skills.
